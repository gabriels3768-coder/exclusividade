# Sistema Exclusividade

Sistema local de gestao com:

- cadastro de clientes, funcionarios, usuarios e fornecedores
- contas a pagar e contas a receber
- centro de custo e fechamento de caixa
- estoque com importacao por planilha
- PDV com crediario
- relatorios, exportacoes e auditoria

## Iniciar

1. Abra [iniciar-sistema.bat](C:/Users/Pc/Documents/Sistema-exclusividade/iniciar-sistema.bat)
2. Ou abra [abrir-sistema.bat](C:/Users/Pc/Documents/Sistema-exclusividade/abrir-sistema.bat)
3. Acesse [http://localhost:3000](http://localhost:3000)
