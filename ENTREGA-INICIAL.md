# Configuracao Inicial de Entrega

## Antes de entregar ao cliente

1. Confirmar que o sistema abre em `http://localhost:3000`
2. Criar ou revisar o usuario administrador do cliente
3. Trocar senha padrao por senha do cliente
4. Conferir backup funcionando
5. Deixar um backup limpo da base inicial
6. Validar cadastro, estoque, financeiro, PDV e relatorios

## Entrega recomendada

- pasta do sistema completa
- banco em [data/system.db](C:/Users/Pc/Documents/Sistema-exclusividade/data/system.db)
- atalho [abrir-sistema.bat](C:/Users/Pc/Documents/Sistema-exclusividade/abrir-sistema.bat)
- manual [MANUAL-USUARIO.md](C:/Users/Pc/Documents/Sistema-exclusividade/MANUAL-USUARIO.md)

## Acesso inicial

- cadastrar usuario do cliente
- pedir para o cliente trocar a senha no primeiro acesso

## Procedimento de backup

- orientar backup diario ou semanal, conforme o uso
- guardar copia fora da pasta principal

## Itens para implantacao

- clientes iniciais
- fornecedores
- categorias
- produtos
- centros de custo
- usuarios

## Observacao comercial

Se for vender para terceiros, entregue sempre:

- usuario inicial funcionando
- base limpa ou base do cliente importada
- manual curto
- procedimento de backup explicado
